FREEDOMCHAT — запуск и размещение

Что добавлено:
- requirements.txt — зависимости Python;
- Procfile — команда запуска веб-сервера;
- render.yaml — конфигурация автоматического размещения на Render;
- маршрут /health для проверки доступности сайта;
- запуск на адресе 0.0.0.0 и порту из переменной PORT;
- SECRET_KEY берётся из переменной окружения.

ЛОКАЛЬНЫЙ ЗАПУСК
1. Установите Python 3.12.
2. Откройте терминал в папке проекта.
3. Выполните:
   pip install -r requirements.txt
4. Запустите:
   python app.py
5. Откройте в браузере:
   http://127.0.0.1:5000

РАЗМЕЩЕНИЕ НА RENDER
1. Распакуйте архив.
2. Загрузите содержимое папки FreedomChat.zip в новый GitHub-репозиторий.
   В корне репозитория должны лежать app.py, models.py, requirements.txt и render.yaml.
3. На Render создайте новый Web Service и подключите этот репозиторий.
4. Render прочитает render.yaml и установит зависимости/запустит Gunicorn.
5. После успешного Deploy откройте выданный Render адрес сайта.

ВАЖНО ПРО БАЗУ ДАННЫХ
Существующий SQLite-файл сохранён. На некоторых бесплатных хостингах локальные файлы
могут сбрасываться при перезапуске или новом Deploy. Для постоянного хранения аккаунтов
и сообщений на публичном сайте подключите постоянный диск или PostgreSQL и настройте
DATABASE_URL. Не публикуйте секреты и не используйте тестовые пароли.

Если сайт уже размещён, одних файлов в архиве недостаточно: исправленную версию
нужно повторно загрузить на хостинг и выполнить Deploy. Сам архив не создаёт
публичный интернет-адрес автоматически.
